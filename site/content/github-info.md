## Latest updates

- **Agentic workflows for repository automation.** You can describe automation in plain markdown and compile it with `gh aw compile` into a hardened GitHub Actions lock file. Workflows are read only by default, and write actions such as opening a pull request go through safe outputs so a person always reviews the change. Source: [GitHub Agentic Workflows docs](https://github.github.com/gh-aw/).
- **Ready made workflow ideas.** The Awesome Copilot workflows collection gathers community agentic workflows you can study and adapt for triage, reporting and content updates. Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/).
- **Where to watch for news.** New features land first on the [GitHub Blog](https://github.blog/latest/) and the [GitHub Changelog](https://github.blog/changelog/). Mona's updater workflow checks both every day and proposes changes here through a pull request.
